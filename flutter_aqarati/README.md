# 🏢 تطبيق عقاراتي (Flutter)

تطبيق عقاراتي المتكامل للوساطة العقارية وحاسبة التمويل العقاري المتطورة، مصمم بالكامل باستخدام إطار عمل **Flutter** ولغة **Dart** بنمط Material 3 الداكن الأنيق.

---

## ✨ مميزات التطبيق

1. **تصفح العقارات (Explore)**:
   - بحث فوري بالمدينة أو الحي.
   - تصفية متعددة (حسب الغرض: للبيع / للإيجار، نوع العقار: فيلا / شقة / دور / أرض، والمدينة).
   - بطاقات تفاعلية تعرض المساحة، عدد الغرف، دورات المياه، والسعر بتنسيق العملة المحلية.

2. **تفاصيل العقار (Property Details)**:
   - معرض صور مع شارات الغرض والنوع.
   - قائمة بالمرافق والمميزات (مسبح، مصعد، حديقة، كاميرات).
   - بطاقة الوسيط المعتمد برقم رخصة فال مع إمكانية الاتصال المباشر عبر الهاتف أو محادثة الواتساب بنقرة واحدة.
   - اختصار حاسبة التمويل السريع للعقار.

3. **حاسبة التمويل العقاري (Mortgage Calculator)**:
   - حساب القسط الشهري، إجمالي التكلفة، وإجمالي الأرباح بدقة رياضية.
   - أشرطة سحب تفاعلية (Sliders) مع خيارات سريعة للأسعار وسنوات السداد (10 إلى 30 سنة).
   - نسبة الربح السنوية التقديرية (APR).

4. **المفضلة (Favorites)**:
   - حفظ العقارات وإدارتها محلياً مع شارة عدد العقارات في شريط التنقل.

5. **إضافة إعلان عقاري جديد**:
   - نموذج متكامل لنشر العقارات مع التحقق من صحة المدخلات.

---

## 🚀 كيفية تشغيل المشروع على جهازك

### المتطلبات الأساسية:
- تثبيت [Flutter SDK](https://flutter.dev/docs/get-started/install) (الإصدار 3.0 فما فوق).
- تثبيت محرر أكواد مثل **VS Code** أو **Android Studio** مع إضافة Flutter & Dart.

### خطوات التشغيل:

1. **فك الضغط**:
   قم بفك ضغط الملف المحمّل، ثم افتح مجلد `flutter_aqarati` في الطرفية (Terminal) أو داخل محررك (VS Code / Android Studio).

2. **تثبيت الحزم (Dependencies)**:
   ```bash
   flutter pub get
   ```

3. **تشغيل التطبيق**:
   - لتشغيل التطبيق على الهاتف الموصول أو المحاكي:
     ```bash
     flutter run
     ```
   - أو لتشغيل التطبيق على متصفح الويب (Chrome):
     ```bash
     flutter run -d chrome
     ```

4. **بناء نسخة أندرويد نهائية (APK)**:
   ```bash
   flutter build apk --release
   ```
   ستجد ملف الـ APK الناتج في المسار:
   `build/app/outputs/flutter-apk/app-release.apk`
